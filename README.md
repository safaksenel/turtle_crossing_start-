## 🎮 Oyun Hakkında / About

**[TR]**  
Klasik *Frogger* mekaniklerinden esinlenerek Python standart kütüphanesi olan `turtle` ile geliştirilmiş 2D arcade oyunudur. Oyuncu kaplumbağayı kontrol ederek hızla geçen arabalara çarpmadan karşıya geçirmeye çalışır. Her başarılı geçişte araba hızı ve zorluk seviyesi artar.

**[EN]**  
A 2D arcade survival game inspired by the classic *Frogger*, built with Python's native `turtle` graphics framework. Players guide a courageous turtle across a multi-lane highway avoiding high-speed oncoming traffic. Each successful crossing increments the level score and vehicle velocity.

---

## 🕹️ Nasıl Oynanır? / How to Play

- **Yukarı Ok Tuşu (Up Arrow):** Kaplumbağayı ileri hareket ettirir.
- **Hedef:** Karşı kaldırıma ulaşarak seviye atlamak ve en yüksek skoru elde etmek!

---

## 🚀 Çalıştırma / Run

Ek bir paket kurulumuna gerek yoktur (Python standart kütüphanesi kullanılır):

```bash
python main.py
```
